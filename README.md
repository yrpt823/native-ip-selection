## 什么是原生IP，下单前怎么自己验

原生 IP 指一个地址的注册国、广播它的网络、地理定位数据库里的记录、服务器的真实位置，这四项指向同一个国家。广播 IP 或借用 IP 是在 A 地广播、却注册或标注成 B 地，不同数据库可能给出不同国家，数据库一更新，记录还会变。

| 对比项 | 原生 IP | 广播 / 借用 IP |
| --- | --- | --- |
| 注册国家 | 服务器所在国 | 常常是另一个国家 |
| 广播来源 | 该国的本地网络 | 一地广播，注册或标注为另一地 |
| 地理定位数据库 | 与服务器所在国一致 | 不同数据库可能显示不同国家 |
| 服务器真实位置 | 与 IP 声称的国家相符 | 可能与声称的国家相距很远 |
| 长期一致性 | 稳定 | 数据库更新时可能变化 |

这张对照表是 JUSTG 在其原生 IP 说明页给出的判断依据，也是各家说法里比较好操作的一种。

验的方法有三步，一台刚拿到的机器十分钟能跑完。

第一步，跑 whois。在 Linux 或 macOS 上执行 `whois 你的IP`，看 country 字段和 network owner。日本、韩国的地区注册机构是 APNIC，北美是 ARIN，注册机构和国家对不上，后面的都不用看了。

第二步，把同一个 IP 放进两到三个公共地理定位数据库，比较它们报的国家和城市。原生 IP 在这几个库里显示同一个国家。

第三步，查 ASN。whois 记录和多数查询工具都会显示宣告这个 IP 的自治系统，它应该是目标国家里实际运营的网络，而不是某个云厂商的数据中心段。

新分配的 IP 有可能短时间内还显示旧数据，各家数据库刷新周期不同，隔一天再查一次比较稳妥。

有件事得提前说清楚。JUSTG 在说明页里明确写了，原生 IP 只描述服务器的真实位置，不保证能访问任何第三方服务，也不是绕过谁的服务条款或地区规则的办法。原生 IP 只解决“这个地址在地理上属于哪里”，能不能解锁某个平台是另一回事，平台的策略随时会变。

## 下单流程和售后：哪几步是通行做法，哪些要提前问

各家流程大同小异，通用的是六步：注册账号（邮箱即可）→ 在商品列表里选地区和 IP 类型 → 选计费周期 → 支付宝、微信或 PayPal 付款 → 在控制台取 IP 和初始密码或密钥 → SSH 连上去跑一遍 whois 验证。

差异出在细节上，下单前值得看清。

登录方式。DMIT 默认不支持密码登录，只能用 SSH 密钥，订单页要先粘贴公钥，连的时候用 `ssh -i 私钥路径 root@IP`。LisaHost 是给初始密码直接连。六六云官网写的是 60 秒开通、可视化控制台可自助重装系统和重置密码。

实名与验证。LisaHost 明确写没有实名或 KYC 要求。其他几家我没有查到明确说明，需要自己确认。

系统选择。六六云多款套餐标了“其他档位可选 Windows”，百云的美国家宽系列支持 Windows 和多种 Linux，LisaHost 只有部分套餐支持 Windows，购买前看套餐说明里有没有标注。DMIT 的指南推荐 Debian 12 或 Ubuntu 22.04 LTS。
